# Stock screener reports

Generated by the `stock-screener` GitHub Actions workflow every weekday after the
US close (or locally, see the README).

- `latest.md` / `latest.json` — price screen: Top-100 leaderboard and breakout watchlist
- `history/<date>.json` — one snapshot per run, used for "what changed" diffs
- `catalysts/latest.md` / `latest.json` — Claude web-search scan for pre-boom setups
  (`python -m stocks.catalysts`), each candidate cross-referenced with the price screen
- `catalyst-research-<date>.md` — hand-compiled research notes
