# Stock screener reports

Generated by `python -m stocks.cli` (see `stocks/` and the
`stock-screener` GitHub Actions workflow, which runs every weekday after the
US close).

- `latest.md` / `latest.json` — most recent Top-100 leaderboard and breakout watchlist
- `history/<date>.json` — one snapshot per run, used for "what changed" diffs
  and for later back-testing of the breakout signals
